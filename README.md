Wireshark Network Traffic Analysis Lab

Overview

This project documents my hands-on Wireshark practice, inspired by a lab provided by **NETWORKWALKS**.

The lab motivated me to install Wireshark on my Kali Linux virtual machine and explore network traffic analysis.

 Objectives
- Capture and analyse network packets.
- Identify source and destination IP addresses.
- Understand TCP SYN, SYN-ACK and RST flags.
- Identify open and closed port responses.
- Identify attacker IP and Target IP
- Observe connection attempts and potential port-scanning activities.

Tools Used
- Wireshark Lab provided by NETWORKWALKS

Learning Experience
I encountered challenges during the initial stages, but consistency and continuous practice helped improve my understanding of Wireshark.

I am still learning, but this practical exercise has strengthened my knowledge of network traffic analysis and cybersecurity fundamentals.
